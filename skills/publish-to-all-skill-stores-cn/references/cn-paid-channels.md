# 国内付费渠道与定价

**默认立场：能收费的渠道就收费。** 免费渠道留引流版，付费渠道挂完整版或 Pro 版；
同一个技能在不同渠道是不同 SKU，不必同价。

## 最要紧的一条：能不能收费取决于「形态」，不取决于「渠道」

2026-10 实测国内两家：

- **腾讯 SkillHub / SkillPay**：平台**暂不收取技术服务费**（0 抽成），按次计费、单价自定，
  支付宝 / 微信实时结算到绑定账户。**但它只认 Pay Skill**——安全设计上要求
  「源文件依赖后端服务，脱离后端无法独立使用」，并按「确认支付 → 返回支付触发标识 →
  任务内继续执行」改造调用链。**纯本地脚本型技能无法直接变成 Pay Skill。**
  入驻本身很快：实名认证 + 绑定支付宝即可。
- **阿里云百炼 Agent Store**：Agent 变现体系（AI 打赏 + 统一分账 + 支付宝收付），
  本质是「服务商 / ISV 侧的分账」，同样要求交付的是**可调用的服务**，而不是一个 SKILL.md 文件夹。

结论：**"能收费"通常等于"你有后端"。** 一个纯 Agent Skill 想收钱，只有两条路：
① 找到接受「打包文件 + 价格字段」的市场；
② 把技能升级成带后端调用的服务（腾讯 Pay Skill / 百炼 Agent），这时才轮到 0 抽成或 70% 分账。

| 渠道 | 收费方式 | 分成（开发者拿） | 准入门槛 |
|---|---|---|---|
| **腾讯 SkillPay** | 按次，单价自定（支付宝/微信） | **100%（平台暂不收技术服务费）** | 实名 + 绑定支付宝/微信商户号；**须改成依赖后端的 Pay Skill** |
| **扣子 Coze** | 按次（可低至 ¥0.5/次）/ 月订阅 | 约 **70%** | 需入驻商户 `code.coze.cn/merchant-management` |
| **阿里云百炼 Agent Store** | 打赏 + 统一分账 + 支付宝收付 | 按 ISV 分账协议 | 需服务商/ISV 身份，交付可调用服务 |
| **字节 Find Skill** | 未公开 | 未公开 | 火山引擎侧入口 |
| **Dify 市场** | 自接支付 | 私有部署 **0%** | 自部署 |

**共同点：定价动作全部发生在"账号/商户"层，不在"提交"层。**
支持「从 GitHub 导入」与「上传 zip」的渠道**都设不了价**，它们只做免费收录。

所以正确做法是：**先用免费渠道抢曝光位，同时把付费 listing 的字段全部填好，
等账号/商户资质到位后一次粘贴。**

## 定价经验值

- 低于 **¥20** 会被默认当成"自用玩具"，反而不如免费
- **¥35**（约 $5）是"有人真会买"的最低舒适区
- 拆 SKU 比抬价有效：核心免费引流 → Pro 适配器包 → 数据集 / ID 库

## 合规红线（写进 listing 的说明里）

- 不承诺破解、不绕过 DRM、不涉及联机 / 排行榜 / 反作弊
- 明确"只处理用户自己合法拥有的副本"
- 含脚本的技能主动披露：零依赖、无网络、无动态执行、写入前强制备份
- 审核索要补充材料时，**加说明而不是删功能**——安全能力就是卖点
